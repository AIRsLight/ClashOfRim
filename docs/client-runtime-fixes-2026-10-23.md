# 客户端定向修复（2026-10-23）

## 密码输入显示

- 本机 RimWorld 为 `1.7.4985 rev1269`。`UnityEngine.GUI.PasswordField` 的实现忽略 `maskChar`，将原文交给通用文本框。仅替换控件名称不能修复此问题。
- 新增共享 `ClashPasswordField`，保留原版文本编辑，在该控件调用期间遮蔽绘制与光标测量使用的文字；输入法组合文本也经过遮蔽。`finally` 恢复绘图后端，不改变后续普通输入框。
- 登录、注册及确认密码、账号改密、管理员重置密码统一使用此控件。产品版本升为 `0.4.5`，协议不变。参考程序集同步至 `1.7.4985-unstable`，匹配本次绘图接口；1.6 冻结包不改动。
- 定向测试执行实际原版 GUI 编辑逻辑，覆盖原文保持、键入、退格、全选粘贴、中文和代理对字符、富文本样式字符、输入法组合文本、绘制异常恢复及后续普通文本框。4 个相关测试组通过；本机程序集与 NuGet 参考程序集构建均通过。
- 本轮为单元测试及构建验证，未进行全量游戏回归或发布。

## 远程地图计划标记

- 1.7 将绘制的计划保存在 `PlanManager`，不在原有蓝图、框架及施工 designation 的清理范围内。
- 在共享施工清理器中调用原版 `Plan.Delete(false)`，同时清理计划列表、格子索引、显示网格和当前选中项。观察、袭击准备及延迟载入的子地图复用现有调用链。
- 单元测试运行实际 `Plan` / `PlanManager` 删除逻辑，仅替代绘图设备和全局选择器入口。覆盖多格计划、隐藏计划、空计划、选中计划、重复清理、独立子地图和本地地图隔离；远程地图兼容测试组通过。

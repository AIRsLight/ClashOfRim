# 远程地图指令清理（2026-10-25）

## 原因与修复

- 原实现仅按名称清理四类施工指令，因此遗漏开采及其他原版、模组指令。远程副本不应继承源殖民地的工作命令，逐项扩展名单无法覆盖未知模组。
- 删除类型白名单与施工目标判断，对远程副本的全部 designation 调用原版 `DesignationManager.RemoveDesignation`，同步更新格子、物品、工作索引与绘制缓存。包含界面不可取消的指令，不销毁目标物品或矿石。
- 蓝图、框架及 1.7 独立计划标记继续由原有公共清理器处理。观察、袭击准备及延迟导入的子地图复用同一入口；不修改源存档或本地殖民地。
- 产品版本预备为 0.4.10，协议及冻结 1.6 内容不变。

## 定向验证

- 使用真实 `DesignationManager`，仅隔离视觉特效与日志；覆盖开采、矿脉开采、狩猎、施工、第三方不可取消指令、同格多个指令及无矿石对象的格子目标。
- 检查清理计数、格子/物品/工作索引、绘制缓存、目标物品保留、重复调用、子地图和本地地图隔离。
- 远程地图兼容、子地图生命周期、袭击战场接入三个相关测试组通过，日志 `LocalOnly/remote-orders-tests.log`。
- 按用户要求仅做定向单元测试，未运行全量 RimTest，未推送发布。
